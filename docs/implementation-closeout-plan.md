## 完成判据

开发者可在当前工作区生成自包含入口和候选包，无需 core；最终用户通过审核后的 HTTPS 包装命令使用，不需 clone 或预装 zsetup。拒绝不具备安装路径的平台，不能静默退回普通 Linux。Token 和身份保留、安全失败优先。群晖人工交接与 Docker 的禁止项必须在用户结果中保留，不能包装成全自动完整生命周期。无真机验收记录的目标继续标工程候选；没有发布回执不标上线。本轮可安全完成的本地集成/测试工作已结束；需要外部设备、权限或身份证据的事项逐项留证，不虚构完成。
