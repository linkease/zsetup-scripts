## 来源核对与修复

`stable-macos` 仍为 0.6.5。原自举只读取 `zsetup/0.6.5/`，而当前 macOS 发布在
`zsetup/macos/0.6.5/`。因此此前针对旧路径的“缺包”结论不能代表新平台目录缺包。

优先读取平台目录清单，兼容旧平铺目录；版本来自 stable，不硬编码 0.6.5。
选中摘要后固定二进制相对目录，并使用相同架构文件名。macOS 无有效摘要或无校验工具
时拒绝执行，不通过 HTTP 或跳过校验掩盖元数据错误。原有镜像顺序保留。

## 发布与回滚边界

共享自举改动会重新生成其他应用的可变 shell 入口；没有重写其他应用已发布的版本安装器。
DDNSTO 0.3.0、0.3.1 保持不变，新增 0.3.2、索引和全局摘要由构建统一生成。
控制台命令及 ddnsto-static 不需要改。只有脚本发布后，线上入口才会使用该适配。
正式发布及完整应用真机验收尚未执行，需另行安排；回滚只切换入口/索引，不删除历史文件或降级设备。
