# Scoop Windows application

`business.ps1` and `main.ps1` are the maintained sources. `scoop-install.ps1`
is generated by `python3 -B scoop/build.py`; never edit the generated entry.

The immutable `0.1.0` entry owns a user-level transaction. Online installation
downloads the locked M4 runtime bundle only through canonical `zsetup download`,
then uses its ephemeral KSpeeder and `ks-cli scoop bootstrap
--require-accelerated` to fetch the pinned Core/Main archives. Both receipts
must report `admin_proxy`; there is no origin fallback.

`--installer-bundle ABSOLUTE_PATH` is a separate, explicit offline rescue path.
Build that sealed input with `scripts/package-scoop-sealed.py`; it contains the
same runtime, Core/Main locks and manifests and never falls back to networking.
The installer rejects elevation by default, system scope, unsafe/reparse paths,
and non-empty unowned roots. `--installer-allow-admin` is an explicit test or
operator override, not an implicit `RunAsAdmin` mode.

Root activation, Scoop config and user PATH are rolled back together. A
LinkEase-owned receipt makes repeat installs idempotent and permits later
managed upgrades while preserving unrelated installed applications. The entry
does not change zsetup core, `stable-windows`, Machine PATH, services, system or
Git proxy settings, and the release tooling does not publish public pointers.
