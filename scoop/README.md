# Scoop Windows application candidate

`business.ps1` and `main.ps1` are the maintained sources. `scoop-install.ps1`
is generated by `python3 -B scoop/build.py`; never edit the generated entry.

M5 validates the Windows-only publishing seam. Its immutable `0.1.0-m5`
candidate only supports a read-only `--explain --json -- ARGS` invocation so
the real Windows zsetup argv boundary can be tested without claiming Scoop is
installed. M6 replaces this candidate with a new immutable application version
that owns the user-level transaction. Neither candidate changes zsetup core,
`stable-windows`, Machine PATH, services, or public release pointers.
